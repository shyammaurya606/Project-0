# 🏋️ Fitness Club Website

This is a simple responsive landing page for a **Fitness Club**, built using **HTML5** and **CSS3**.  
It includes a navigation bar, logo, call-to-action buttons, and a registration form for new members.

---

## 📌 Features
- Clean and modern UI with background image.
- Navigation bar with links:
  - Home
  - About Us
  - Fitness Calculator
  - Contact Us
- Call-to-action buttons:
  - Call Us Now
  - Email Us
- Registration form with fields for:
  - Name
  - Age
  - Gender
  - Locality
  - Phone Number
  - Email
- Styled form and buttons with hover effects.
