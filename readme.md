## 🏋️ Fitness Club Website

A simple landing page for a **Fitness Club** with navigation, call-to-action buttons, and a registration form.

### ✨ Features
- Navigation bar with sections: Home, About Us, Fitness Calculator, Contact Us  
- Call-to-action buttons: Call Us Now, Email Us  
- Registration form with fields:
  - Name  
  - Age  
  - Gender  
  - Locality  
  - Phone  
  - Email  
- Modern UI with hover effects and styled components
